## Traps

- **Line endings.** Most sources are CRLF on both branches (`effect.cpp`, `renderfunctions.cpp`, …). These are CRLF on main and LF on 2.0.x, so a cherry-pick conflicts on the whole file: `main.cpp`, `engine/cacher.cpp`, `engine/cacher_audio.cpp`, `engine/cacher_video.cpp`, `ui/timelinewidget_paint.cpp`, `ui/timelinewidget_ghosts.cpp`, `ui/blur.{h,cpp}`. Port those by hand or with `git apply --ignore-whitespace -3`, keep the target's endings (check with `file`), never `git clang-format`. Recompute by looping over files common to both trees and comparing `git show origin/main:f | grep -c $'\r$'` with the same on `origin/2.0.x:f`.
- **Nothing was renamed or deleted.** `git diff --find-renames --name-status origin/main origin/2.0.x -- src` is 45 A, 241 M, 0 D/R. "Moved" code means the old file stays, slimmed or turned into a shim, and the new file sits alongside. A 1.x fix always finds its file on 2.0.x, but the code may no longer be in it (see the map).
- **amber-engine boundary is a convention.** The OBJECT library (`src/CMakeLists.txt:128-200`, plus `target_sources` in `src/core/CMakeLists.txt` and `src/engine/CMakeLists.txt`) links `Qt6::Widgets`; a UI include in engine code compiles. Existing violations: `texteffect.cpp`, `timecodeeffect.cpp`, `volumeeffect.cpp`, `richtexteffect.cpp`, `subtitleeffect.cpp`, `project/media.cpp`, `project/loadthread.cpp`, `global/debug.cpp`. Don't add more: route UI calls through `amber::app_ctx`. Test binaries link through `tests/test_ui_stubs.cpp` / `tests/test_appcontext_stub.h`; a new UI symbol used from engine code or a new `AppContext` virtual needs a stub there or the tests fail to link.
- **New source file:** engine-side goes into the amber-engine list (or `core/`/`engine/` subdir CMakeLists), UI-side into `UI_SOURCES`. Effects shaders go into `AMBER_EFFECTS` (main: `OLIVE_EFFECTS`).
- **Renames** main → 2.0.x:
  - CMake `OLIVE_{SOURCES,RESOURCES,EFFECTS,QM_FILES,TARGET,EXPORT_PRESETS,DEFINITIONS}` → `AMBER_*` (`OLIVE_SOURCES` split into `UI_SOURCES` + amber-engine); define `OLIVE_OCIO` → `AMBER_OCIO`; env `OLIVE_EFFECTS_PATH`/`OLIVE_LANG_PATH` → `AMBER_*`.
  - `OliveGlobal` → `AmberGlobal` (pointer still `amber::Global`), `OliveAction` → `AmberAction`, `kOliveDefault*` → `kAmberDefault*`, `LabelSlider::DisplayType` → `amber::DisplayType` (`core/displaytype.h`).
  - Globals `recent_projects` / `autorecovery_filename` → `amber::project_io->recentProjects()` / `autorecoveryFilename()`.
  - `kTrackMinHeight` 30 → 15; its paint uses split into `kClipTriangleSize` (7, was `kTrackMinHeight >> 2`) and `kWaveformMinClipHeight` (20). A main hunk comparing against `kTrackMinHeight` in paint code usually maps to one of these.
- **AppContext** exists on both branches; 2.0.x adds `showQuestion`, `showSaveFileDialog`, `showOpenFileDialog`, `clearViewerMedia`, `getMainWindow`, `clearGraphEditorIfRow` (`core/appcontext.h:41-46`). Direct `QMessageBox`/`QFileDialog` calls in `effect.cpp`, `internal/vsthost.cpp`, `transition.cpp` are gone on 2.0.x; a main fix adding one there becomes an `app_ctx->` call.
- **Executable** is `amber-editor` on both. `docs/2.0-spec.md` is tracked on 2.0.x despite `docs/` being gitignored; the rest of `docs/` is local only.
- **PRs:** fetch with `git fetch origin pull/N/head:refs/remotes/pr/N`. Merge on main with `gh pr merge N --squash --subject "..." --body ""` (keeps the author, no trailers), then port to 2.0.x with `git cherry-pick` (author preserved). Never `-X theirs`/`-X ours`: it silently drops one side of every conflicting hunk.

## Tests

- 2.0.x (18): amber-tests, amber-engine-tests, amber-test-{path,audio,headers,srt,effects,projectio,shortcutfile,keyframes,undo-markers,clipboard,deletion-plan,rhi-smoke,rendering,timeline-layout,recordingtap,effects-gpu}. All but timeline-layout and recordingtap link amber-engine.

- Real coverage, so a green run isn't oversold: `rhi-smoke` and `rendering` only create an OpenGLES2 QRhi, a texture and a clear/readback; `projectio` tests ProjectIO state (modified flag, recents, sequence history, autorecovery signal), no `.ove` round trip; `effects-gpu` (~73 cases) is the only pixel-level net (internal, blur, distortion, color/key effects, YUV/NV12 decode, keyframed transform). Nothing renders a LUT, Corner Pin or a full sequence end to end.
- Build in a separate dir (`build20/` for 2.0.x) with `-j16`, then `ctest --test-dir build20`.
